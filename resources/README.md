# resources/

Файлы, которые НЕ являются Python-кодом, но требуются в рантайме.

## `meta_ru.md`

Сезонная мета на русском. Целиком попадает в системный промпт Gemini.
Обновляй при каждом мажорном патче.

## `digit_templates/`

PNG-шаблоны цифр HUD-шрифта Apex (0.png … 9.png), single-channel grayscale.
Нужны для быстрого распознавания HP / щита / патронов через
`apex_coach.vision.digits.DigitMatcher`.

**Как получить:**

1. Запусти игру в окне (1920×1080) с заполненным магазином/HP.
2. Сделай скриншот, вырежи отдельные цифры (примерно 32 пикселя в высоту).
3. Сохрани как `0.png` … `9.png` в этой папке.

В MVP шаблоны не приложены — `DigitMatcher` корректно возвращает `None`,
и приложение продолжает работать (теряются только числовые подсказки).

## `legend_icons/`

Темплейты иконок легенд для `apex_coach.vision.legend_icons.LegendIconMatcher`.
По одному PNG-файлу на легенду, имя файла — слаг из `LEGEND_KB` (например
`wraith.png`, `octane.png`, `sparrow.png`). Файлы — quadratic grayscale,
любой разумный размер (≥ 40 px); матчер сам нормализует.

**Как получить:**

1. Сделай скриншот игры с открытой сквад-панелью (верхний-левый угол HUD).
2. Вырежи квадратную область с портретом каждой легенды (можно через
   crop в любом редакторе).
3. Сохрани как `{slug}.png` в этой папке. Список валидных слагов — ключи
   `apex_coach.tactics.knowledge.LEGEND_KB`.

Если папка пустая, `LegendIconMatcher` пишет один INFO-лог и тихо
отключает детекцию — приложение продолжает работать без распознавания
легенды (тип ульты пропадёт из подсказок).
